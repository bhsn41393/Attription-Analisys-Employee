# 📊 HR Employee Attrition & Performance Analysis Dashboard

## 📌 Project Overview
This project presents an interactive **HR Analytics Dashboard** built in Power BI to analyze employee attrition trends, identify key factors contributing to turnover, and support data-driven decision-making for HR management[cite: 2].

The dataset includes **882 employees** with various demographic, workplace, and satisfaction metrics[cite: 2].

---

## 🔑 Key Metrics & Insights
* **Total Employees:** 882[cite: 2]
* **Attrition Rate:** ~17% (150 Employees left)[cite: 2]
* **Average Age:** 36.65 years[cite: 2]
* **Average Salary:** $6,380[cite: 2]

---

## 📈 Key Findings
1. **Overtime Impact:** Employees working overtime show a significantly higher rate of attrition compared to non-overtime staff[cite: 2].
2. **Job Roles at Risk:** The highest attrition rates are concentrated in specific roles like **Laboratory Technicians**, **Sales Executives**, and **Sales Representatives**[cite: 2].
3. **Satisfaction & Balance:** Low ratings in **Environment Satisfaction** and **Work-Life Balance** closely correlate with employee turnover[cite: 2].
